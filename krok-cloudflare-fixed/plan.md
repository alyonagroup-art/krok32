# План переработки «Крок»

## Цель
Превратить короткий демонстрационный урок в полноценный учебный цикл по каждой готовой теме: глубокое объяснение, 20–30 разобранных примеров, многоуровневая практика, ДЗ, самостоятельная на 50 вопросов, контрольная на 100 вопросов, тест, оценивание и рекомендации по ошибкам.

## Реализация
- Сохранить монорепозиторий `packages/core` / `packages/content` / `apps/web`.
- В интерфейсе темы явно показать маршрут из 8 этапов и ожидаемый объём каждого этапа.
- Перед стартом ДЗ/самостоятельной/контрольной показать структуру работы: уровни сложности, количество, время, шкалу оценки и итоговые артефакты.
- В результатах сессии показывать 12-балльную оценку, процент, количество ошибок по навыкам и конкретный план повторения.
- Для каждой готовой темы сохранить генеративную базу: подбор задач по сложности, без повторов в сессии, детальный разбор каждой ошибки.
- Добавить в контентную валидацию проверку минимальной глубины (урок, примеры, генераторы, решения, шаги), чтобы поверхностные темы не считались готовыми.

## Дизайн
Сохраняется выбранный стиль «дружня STEM-майстерня з редакційною ясністю»: спокойная тетрадная поверхность, жёлтый маркер следующего шага, синяя алгебра/фиолетовая геометрия, постоянная панель прогресса. Новые блоки используют редакционную структуру: этап, объём, цель, критерий готовности.

## Критерии готовности
- Ученик видит, что тема — это не 3 примера, а полноценный маршрут подготовки.
- ДЗ = 30, самостоятельная = 50, контрольная = 100 заданий; отображаются шкала и формат.
- После завершения видны процент, оценка /12, слабые навыки, ошибки с решениями и точные рекомендации.
- `npm run build` и `npm run validate` проходят.
